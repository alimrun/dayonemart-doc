Drop your actual, ANNOTATED screenshots into this folder using the exact
file names below. The documentation already references these files, so once
you add them the placeholder boxes are replaced automatically.

"Annotated" means add arrows, numbered callouts (1, 2, 3, 4), or highlight
boxes pointing to the important areas. Each doc page lists the numbered
callouts to match — mirror those numbers on the image.

FORMAT
------

  - Admin / web screens:  1200-1600px wide
  - Mobile app screens:   ~1080px wide (a single phone frame)
  - Keep each file under ~400 KB where possible
