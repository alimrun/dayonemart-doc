SCREENSHOTS — REQUIRED BEFORE RESUBMISSION
============================================

Drop your actual, annotated screenshots into this folder using the exact
file names below. The documentation already references these files, so once
you add them the placeholder boxes are replaced automatically.

Use PNG, recommended width 1200-1600px. "Annotated" means add arrows,
numbered callouts, or highlight boxes pointing to the important fields.

Required files
--------------
admin-settings.png
    A screenshot of Admin Panel -> Settings showing the main configuration
    (business setup / payment / Firebase). Annotate the key fields a buyer
    must fill in.

customer-app-settings.png
    A screenshot of the Customer App settings / configuration screen
    (e.g. the in-app Settings page or the app_constants.dart baseUrl area).
    Annotate where the backend URL / options are set.

deliveryman-app-settings.png
    A screenshot of the Deliveryman App settings / configuration screen.
    Annotate the relevant options.
