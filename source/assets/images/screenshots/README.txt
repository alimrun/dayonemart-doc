SCREENSHOTS
===========

This folder contains the annotated screenshots referenced by the offline
documentation pages. Each image carries numbered callouts (1-4) that match
the "Key areas of this screen" legend printed under the figure in the docs.

ADMIN PANEL  (used by source/pages/admin-and-web.html)
  admin-dashboard.png    Dashboard — KPI cards, order status, sales trend
  admin-orders.png       Orders — status filters, search, inline status, actions
  admin-products.png     Item List — info, category, price, stock/status
  admin-promotions.png   Coupons — name/code, info, validity, status/actions
  admin-branding.png     Business Setup — name, logo, favicon, brand colors
  admin-settings.png     Business Setup — basic info + settings menu

CUSTOMER APP  (used by source/pages/customer-app.html)
  customer-app-home.png      Home — location, module tabs, banners, categories
  customer-app-checkout.png  Checkout — info, schedule, payment, place order
  customer-app-tracking.png  Order details — status, delivery info, items
  customer-app-settings.png  Settings — language, password, permissions

DELIVERYMAN APP  (used by source/pages/deliveryman-app.html)
  deliveryman-app-dashboard.png  Dashboard — online toggle, earnings, orders
  deliveryman-app-order.png      Order detail — customer, items, status, map
  deliveryman-app-settings.png   Settings — language, password, permissions

INSTALLER  (in ../upload/)
  installer-requirements.png, installer-purchase.png, installer-database.png,
  installer-admin.png, installer-finalize.png, installer-complete.png

To replace a screenshot, save the new annotated PNG over the same file name —
the documentation references these names directly. Keep admin/web captures
1200-1600px wide, mobile captures ~1080px wide, and files under ~400 KB.
